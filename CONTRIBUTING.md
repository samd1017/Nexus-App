## How to contribute

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make your changes.
4. Open a Pull Request against `main`.

## Pull Request review process

All pull requests are reviewed by the maintainer **together with Grok** before they are merged.

- Open the PR as normal on GitHub.
- The maintainer will review the changes with Grok.
- Feedback or requested changes will be left on the PR.
- Once approved, the PR will be merged.

Please keep PRs focused. Large unrelated changes are harder to review and more likely to be asked to be split.

## Code style

- TypeScript + React
- Prettier + ESLint (run `npm run format` and `npm run lint`)
- Prefer clear, readable code over cleverness

## Questions

Open an issue or start a discussion. We are happy to help.
